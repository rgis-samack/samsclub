# 🌐 Sam's Club Inventory System — GitHub Pages Web App v3.0
**Desenvolvido por Samack 697 | RGIS 2026**

Esta pasta `github/` contém a versão **Web estática completa** do Gerador de Crachás de Inventário do Sam's Club, pronta para ser publicada no **GitHub Pages**.

---

### 🚀 Como Publicar no GitHub Pages (Passo a Passo Rápido)

1. Crie um repositório no seu GitHub (ex: `sams-club-crachas`).
2. Envie o conteúdo desta pasta `github/` para o repositório.
3. No GitHub, acesse **Settings** > **Pages**.
4. Em **Build and deployment**, selecione a branch `main` e a pasta `/ (root)`.
5. Clique em **Save**. Em menos de 1 minuto, seu site estará no ar!
