## 🇧🇷 Português (Brasil)

### 📌 Sobre a Versão Web
Esta pasta contém a **versão Web 100% estática** do Gerador de Crachás do Sam's Club, pronta para ser hospedada gratuitamente no **GitHub Pages**.

Ela funciona diretamente no navegador web de computadores, notebooks ou tablets, sem necessidade de instalar qualquer programa.

---

### ✨ Recursos da Versão Web
- 📥 **Arraste e Solte (Drag & Drop)**: Solte planilhas (.csv, .xlsx, .xlsm) em qualquer lugar da tela.
- ⚡ **Geração de PDF no Navegador**: Cria arquivos PDF vetoriais no padrão oficial A4 (Duplo e Único).
- 📐 **Auto-Fit de Texto**: Redimensiona textos grandes para caber nas margens.
- 🛡️ **Segurança Supabase & Telemetria**: Valida licenças e grava acessos remotamente.
- 🔒 **Proteção de Código**: Bloqueio de clique direito e atalhos de inspeção (F12, Ctrl+U).

---

### 🚀 Como Publicar no GitHub Pages em 1 Minuto
1. Crie um repositório no seu GitHub (ex: `sams-club-crachas`).
2. Envie os arquivos desta pasta `github/` para o repositório.
3. Vá em **Settings** > **Pages** no repositório.
4. Escolha a branch `main` e a pasta `/ (root)`.
5. Clique em **Save**. Seu site estará no ar em menos de 1 minuto!

## 🇺🇸 English

### 📌 About the Web Version
This directory contains the **100% static Web Edition** of the Sam's Club Inventory Tag Generator, optimized for free hosting on **GitHub Pages**.

It runs natively inside any browser on desktops, laptops, or tablets with zero installation.

---

### ✨ Web Features
- 📥 **Universal Drag & Drop**: Drop spreadsheets (.csv, .xlsx, .xlsm) anywhere on screen.
- ⚡ **In-Browser Vector PDF Generation**: Produces official A4 print PDFs (Double & Single modes).
- 📐 **Smart Auto-Fit Scaling**: Dynamically resizes large text to prevent border overflows.
- 🛡️ **Supabase Security & Telemetry**: Validates remote permissions and logs telemetry.
- 🔒 **Anti-Tamper Protections**: Disables right-click context menu and inspect shortcuts (F12, Ctrl+U).

---

### 🚀 How to Deploy on GitHub Pages in 1 Minute
1. Create a repository on GitHub (e.g., `sams-club-crachas`).
2. Push all files from this `github/` folder to the repository.
3. Go to **Settings** > **Pages**.
4. Select `main` branch and `/ (root)` folder.
5. Click **Save**. Your web app is live in under 1 minute!
